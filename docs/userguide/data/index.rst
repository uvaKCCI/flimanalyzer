Data Tables
===========
After you load data, you can change the tables to show trends more clearly, change the number of decimal places shown, and in general make the data easier to interpret.

.. list-table::
   :widths: 10 30
   :header-rows: 1

   * - Data Table Tool
     - Description
   * - `Loading Data <load.html>`_
     - Opening and importing data files.
   * - `Adjusting Precision <precision.html>`_
     - Adjusts the number of decimal places shown in the tables.
   * - `Filtering Data <filter.html>`_
     - Hides rows by their category values or by numeric ranges.
   * - `Filter Tool <filtertool.html>`_
     - Creates a new table with only the rows that pass category and range filters.
   * - `Pivoting Data <pivot.html>`_
     - Turns the values of a category column into columns to show trends.
   * - `Unpivoting Data <unpivot.html>`_
     - Turns pivoted columns back into a category column.
   * - `Splitting Data <split.html>`_
     - Creates a separate table for each value of a category column.
   * - `Merge Data <merge.html>`_
     - Combines two data tables by matching their category columns.
   * - `Order Categories <order.html>`_
     - Sets the order of the values in category columns.
   * - `Concatenate <concat.html>`_
     - Stacks two or more data tables, or places them side by side.
   * - `Sort <sort.html>`_
     - Reorders the rows by the values of one or more columns.
   * - `Saving Data <save.html>`_
     - Saves a data table to a file.
