# Saving Data

Data tables can be saved as tab-separated text files (`.txt`) by clicking the `Save All` or `Save View` buttons in the table window. Column headers with several lines are saved on one line, with the lines separated by spaces. After saving, the window is named after the saved file.

When you close a table window that has not been saved since it was made or changed, FLIMAnalyzer asks whether to save it. A file you opened counts as saved until you change it, for example with a filter.

* `Save All`: saves all the data, including rows hidden by filters.
* `Save View`: saves the data as currently displayed. Hidden rows are not saved and cannot be recovered from the saved file.
