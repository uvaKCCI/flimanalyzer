# Sort
The `Sort` tool reorders the data rows by the values of one or more columns.

**Menu Access:** `Data` > `Sort`

**Tool panel icon:** ![](/images/data/sort.png)

## Sorting the Data
Once a data table is open, start `Sort` from the menu or the tool panel. Under `Sort by`, select the columns to sort by. Only columns with numeric values are listed. The rows are sorted by the first selected column; rows with the same value there are sorted by the next selected column, and so on. The selected columns are used in their order in the table, not in the order you select them. `Ascending` sorts from the smallest to the largest value (uncheck it for the reverse), and `Renumber rows` gives the sorted rows new row numbers in their new order. A new sorted table, `Table: Sorted`, is created.
