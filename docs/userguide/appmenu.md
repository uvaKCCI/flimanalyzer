# Menus

## File

* `Open...` and `Import...` load data files. See [Loading Data](/userguide/data/load).
* `Import Settings...` and `Export Settings...` load and save all settings: the import settings, the filters and the settings of each tool. See [Settings](/userguide/settings).
* `Exit` closes FLIMAnalyzer. On macOS it is `Quit FLIMAnalyzer` in the `FLIMAnalyzer` menu (⌘Q).

## Data

The `Data` menu has the tools that change or combine data tables, such as `Sort`, `Filter`, `Split` and `Concatenate`. They become available once a data table is open. See [Data Tables](/userguide/data/index).

## Analysis

The `Analysis` menu has the analysis tools, which are also in the tool panel. See [Analysis](/userguide/analysis/index).

## Plot

The `Plot` menu has the plots. See [Plots](/userguide/plots/index).

## Workflow

The `Workflow` menu runs several tools in one go. See [Workflows](/userguide/workflows).

## Window

The `Window` menu lists all open windows (data tables and plots). Select one to bring it to the front. `Close all windows` closes them.

## Help

* `Documentation` opens this documentation.
* `About FLIMAnalyzer` shows the version. On macOS it is in the `FLIMAnalyzer` menu.
